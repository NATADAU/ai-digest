# AI Дайджест — Просто об искусственном интеллекте

Сайт-агрегатор свежих статей про нейросети и искусственный интеллект для новичков.

## Возможности
- 🎨 Современный дизайн с карточками
- ⚡ Плавные анимации
- 📱 Адаптивная верстка
- 🔗 Ссылки на реальные статьи с Хабра

## Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/ai-digest.git
   cd ai-digest
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   ```

3. **Активируйте его:**
   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`

4. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
python app.py
```

Сайт будет доступен по адресу: http://127.0.0.1:5000

## Технологии
- **Backend:** Python + Flask
- **Frontend:** HTML, CSS, JS (Vanilla)
- **Шрифты:** Inter, Space Grotesk
